---
title: "Systems Thinking over Coding"
summary: "Why I view myself as a Systems Thinker first and a Coder second."
---

Coding is becoming a commodity. The real value lies in understanding the system as a whole—how data flows, how components interact, and how the product solves the user's problem.

I leverage AI tools to handle the implementation details ("the slop"), allowing me to focus on:
- **Architecture**: Ensuring the system is scalable, maintainable, and robust.
- **Simplicity**: Removing unnecessary complexity.
- **User Value**: Delivering features that actually matter.

I don't just write code; I design solutions that happen to be implemented in code.
